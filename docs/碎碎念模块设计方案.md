## 1. 模块概述与目标

### 1.1 定位

"碎碎念"是一个**轻量级短内容时间线**：博主随手记录生活、心情、灵感，按时间倒序排列，与正式博客文章（长文）形成互补。

| 维度 | 正式文章 | 碎碎念 |
|---|---|---|
| 内容长度 | 长文、结构化 | 一句话 / 短段落 / 一张图 |
| 更新频率 | 低 | 高（随时发一条）|
| 信息密度 | 高 | 低、轻快 |
| 互动 | 评论 | 点赞 |

### 1.2 目标

1. **低门槛发布**：一条命令即可新增一条碎碎念，无需进入后台。
2. **时间线浏览**：倒序列表 + 无限滚动，浏览体验流畅。
3. **轻互动**：无登录点赞（浏览器指纹去重）。
4. **可分享**：每条支持锚点深链，可被复制/分享/被搜索引擎抓取。
5. **与现有站点融合**：复用 Fluid 主题的视觉与 Hexo 的构建部署链路，不引入重前端框架。

## 3. 设计方案

### 3.1 信息架构

```
站点导航
├── 首页 /           （文章流）
├── 归档 /archives/
├── 标签 /tags/
├── 关于 /about/
├── 笔记 /notes/
├── 留言 /messages/
└── 碎碎念 /thoughts/   ← 新增
    ├── /thoughts/            第 1 页（最新 20 条）
    ├── /thoughts/page/2/     第 2 页
    └── /thoughts/page/N/     第 N 页（分页页供无限滚动 fetch）
```

### 3.2 页面结构（/thoughts）

```
<main>
├─ 标题区
│   ├─ <h1>碎碎念</h1>  +  「写一条」按钮
│   └─ <p>副标题：「一些不成文的瞬间…」+ 总数
│
└─ 时间线容器
    ├─ 左侧竖线（装饰）
    ├─ <ol data-thought-list>            ← 当前页条目
    │    └─ <li data-thought-item> × 20
    ├─ 分页器 / 加载哨兵
    └─ （下一页由 JS fetch /thoughts/page/N/ 注入）
```

### 3.3 单条碎碎念的 DOM 契约

统一字段命名，便于 CSS/JS 复用（沿用原型语义）：

```html
<li class="thought-item" id="58" data-thought-id="58" data-thought-item>
  <span class="thought-dot"></span>                 <!-- 时间线圆点 -->

  <div class="thought-meta">
    <a class="thought-anchor" href="#58">#58</a>     <!-- 点击复制链接 -->
    ·
    <span>发布于 <span class="thought-time-ago" data-timestamp="1786728737000">刚刚</span></span>
    ·
    <time datetime="2026-08-14T17:32:17Z">08-15 01:32</time>
    <span>周六</span>
    ·
    <button class="thought-like-btn" data-thought-id="58" data-liked="false" data-total="0">
      ♥ <span class="thought-like-count"></span>
    </button>
  </div>

  <article class="thought-entry markdown-body">…正文…</article>
</li>
```

### 3.4 数据模型

#### 3.4.1 内容模型（Hexo 层面）

碎碎念复用 Hexo 的 post 模型，通过 front-matter 标记区分，**不新建独立内容类型**（降低复杂度）：

```yaml
---
title: "关于 dsh 的一点想法"     # 可选，列表不展示，仅作文件名/归档用
date: 2026-08-15 01:32:17        # 发布时间（决定时间线顺序）
thought: true                    # 标记为碎碎念（生成器据此筛选）
---
正文内容（支持 Markdown、图片、链接）
```

关键字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | datetime | 排序依据，倒序 |
| `thought` | boolean | `true` 表示属于碎碎念 |
| `title` | string | 可选，列表按原型不展示标题，仅显示正文 |

#### 3.4.2 点赞模型（Supabase 层面）

```sql
-- 表：一条指纹对一条碎碎念只能点一次赞（唯一约束去重）
create table thought_likes (
  id          bigint generated always as identity primary key,
  target_id   text not null,              -- 碎碎念唯一 id（站点内稳定标识）
  fingerprint text not null,              -- 浏览器指纹（SHA-256，32 位 hex）
  created_at  timestamptz not null default now(),
  constraint uq_like unique (target_id, fingerprint)
);
create index idx_likes_target on thought_likes (target_id);
create index idx_likes_fp on thought_likes (fingerprint, created_at);
```

### 3.5 视觉与交互设计

1. **时间线**：左侧 1px 竖线 + 每条一个圆点节点，圆点颜色按分组循环（rose/orange/amber/sky/indigo/fuchsia），弱化"列表"感、强化"时间流"感。
2. **动效**（CSS keyframes）：
   - `thought-heart-pop`：点赞时爱心 0.45s 弹性放大。
   - `highlight-thought`：深链定位后条目背景高亮 2s 淡出。
   - `bubble-enter/leave`：点赞反馈气泡浮出/消失。
3. **响应式**：移动端隐藏竖线与圆点（`sm:` 断点显示），条目左对齐。
4. **反馈气泡**：点赞三态配色——成功(rose) / 已达上限或已点赞(中性) / 失败(灰)。

### 3.6 状态与数据流

```
[构建时] Hexo 扫描 source/_posts 中 thought:true 的 post
        → 生成器按 date 倒序 → 分页生成 /thoughts/、/thoughts/page/N/
        → 每页 HTML 内直接渲染正文（SSG，利于 SEO）

[运行时]
  相对时间  : 服务端先渲染，客户端 60s + visibilitychange 时刷新
  无限滚动  : IntersectionObserver 监听哨兵 → fetch 下一页 → 提取 .thought-item 注入
  点赞      : 点击 → 乐观更新 +1 → 指纹去重 → Supabase RPC → 回填真实 total / 失败回滚
  深链      : 访问 /thoughts/#58 → 若不在当前页，逐页加载直到出现 → 滚动 + 高亮
```

### 4.2 新增选型

| 用途 | 选型 | 理由 |
|---|---|---|
| 内容筛选/分页 | Hexo 自定义生成器（`scripts/thoughts.js` + `hexo-pagination`）| 零依赖，Hexo 原生能力 |

| 点赞后端 | **Supabase**（已有项目，新增一张表 + 两个 RPC）| 复用现有账号，无需新服务 |
| 点赞客户端 | `@supabase/supabase-js`（CDN）| 与评论体系一致 |

### 4.3 选型对比：原型（Astro）vs 本项目（Hexo）

| 能力 | 原型（Astro） | 本项目（Hexo） | 说明 |
|---|---|---|---|
| 内容源 | Content Collection | `_posts` + `thought: true` | Hexo 无独立内容类型，用标记区分 |
| 列表生成 | 组件 + `<template>` 懒加载 | 生成器 + 分页 + fetch | Hexo 分页更利于 SEO |
| 无限滚动 | IntersectionObserver + template | IntersectionObserver + fetch 分页页 | 思路一致 |
| 点赞 | 自建 `/api/likes` | Supabase RPC | 复用已有 Supabase，更省事 |
| 深链 | `#N` + hashchange | `#N` + hashchange（ID 用序号）| 一致 |
| 相对时间 | timeago 库 | 原生 JS | 更轻 |

### 阶段 2：自定义生成器（/thoughts 列表 + 分页）

**步骤 2.1** 新建 `scripts/thoughts.js`：

```js
// scripts/thoughts.js
const pagination = require('hexo-pagination');

hexo.extend.generator.register('thoughts', function (locals) {
  const cfg = Object.assign({ per_page: 20, order: -1 }, hexo.config.thoughts || {});

  // 筛选所有标记为碎碎念的文章，按日期倒序
  const thoughts = locals.posts
    .filter((p) => p.thought === true)
    .sort('date', cfg.order);

  const total = thoughts.length;

  // 生成 /thoughts/ 与 /thoughts/page/N/
  return pagination('thoughts', thoughts, {
    perPage: cfg.per_page,
    layout: ['thoughts', 'archive', 'index'],
    format: 'thoughts/page/%d/',
    data: {
      title: '碎碎念',
      subtitle: '一些不成文的瞬间，记录生活、心情与灵感',
      total
    }
  });
});

// 注册一个 helper，供布局/任意模板取用（如导航徽标、RSS 等）
hexo.extend.helper.register('thoughts', function () {
  return this.site.posts.filter((p) => p.thought === true).sort('date', -1);
});
```

> `hexo-pagination` 是 Hexo 内置依赖，无需安装。返回的每个分页对象里，当前页文章在 `data.posts`，分页信息在 `data`（`current`/`total`/`pages` 等），布局中通过 `page.posts`、`page.current` 访问。

```js
    setTimeout(function () { el.classList.remove('highlight-thought'); }, 2000);
  }

  // ---- 无限滚动：fetch 下一页，提取 .thought-item 注入 ----
  function loadMore() {
    if (busy || nextPage > totalPages) return;
    busy = true;
    if (loading) loading.hidden = false;
    fetch(location.pathname.replace(/\/?$/, '/') + 'page/' + nextPage + '/')
      .then(function (r) { return r.text(); })
      .then(function (html) {
        var doc = new DOMParser().parseFromString(html, 'text/html');
        var items = doc.querySelectorAll('[data-thought-list] .thought-item');
        if (!items.length) { nextPage = totalPages + 1; return; }
        items.forEach(function (it) { list.appendChild(it); initItem(it); });
        refreshTime();
        nextPage += 1;
      })
      .catch(function () { /* 网络失败静默，下次滚动重试 */ })
      .finally(function () { busy = false; if (loading) loading.hidden = true; });
  }

  if (sentinel && 'IntersectionObserver' in window) {
    new IntersectionObserver(function (entries) {
      if (entries.some(function (e) { return e.isIntersecting; })) loadMore();
    }, { rootMargin: '900px 0px' }).observe(sentinel);
  } else {
    window.addEventListener('scroll', function () {
      if (sentinel && sentinel.getBoundingClientRect().top < innerHeight + 900) loadMore();
    }, { passive: true });
  }

  // ---- 点赞（占位，Supabase 接入见阶段 5）----
  function initLike(li) {
    var btn = li.querySelector('.thought-like-btn');
    if (!btn) return;
    btn.addEventListener('click', function () {
      var count = btn.querySelector('.thought-like-count');
      var total = parseInt(btn.dataset.total || '0', 10);
      if (btn.dataset.liked === 'true') return;
      btn.dataset.liked = 'true';
      btn.dataset.total = String(total + 1);
      count.textContent = total + 1 || '';
      var heart = btn.querySelector('.thought-heart');
      if (heart) {
        heart.style.animation = 'none'; void heart.offsetWidth;
        heart.style.animation = 'thought-heart-pop .45s cubic-bezier(.17,.89,.32,1.49)';
      }
      if (window.dogxiLike) window.dogxiLike(btn.dataset.thoughtId, function (res) {
        btn.dataset.total = String(res.total);
        count.textContent = res.total || '';
      });
    });
  }

  // ---- 深链 ----
  function resolveHash() {
    var id = decodeURIComponent(location.hash.slice(1));
    if (!/^\d+$/.test(id)) return;
    if (document.getElementById(id)) return highlight(id);
    (function step() {
      if (document.getElementById(id)) return highlight(id);
      if (nextPage > totalPages) return;
      loadMore();
      setTimeout(step, 400);
    })();
  }
  window.addEventListener('hashchange', resolveHash);
  resolveHash();
})();
```

### 阶段 5：点赞后端（Supabase，可选）

> 若暂时不做点赞，跳过本阶段，阶段 4 里的点赞按钮会以"本地乐观计数"工作（刷新后丢失）。要做持久化再执行本阶段。

**步骤 5.1** 在已有 Supabase 项目执行 SQL：

```sql
-- 1) 点赞表（唯一约束去重）
create table if not exists thought_likes (
  id          bigint generated always as identity primary key,
  target_id   text not null,
  fingerprint text not null,
  created_at  timestamptz not null default now(),
  constraint uq_thought_like unique (target_id, fingerprint)
);
create index if not exists idx_likes_target on thought_likes (target_id);

-- 2) 点赞 RPC（原子 + 每日上限 10 条）
create or replace function like_thought(p_target text, p_fp text)
returns json language plpgsql security definer as $$
declare
  v_total int;
  v_today int;
begin
  if exists (select 1 from thought_likes where target_id = p_target and fingerprint = p_fp) then
    select count(*) into v_total from thought_likes where target_id = p_target;
    return json_build_object('success', true, 'liked', false, 'total', v_total, 'userToday', 0);
  end if;

  select count(*) into v_today from thought_likes
   where fingerprint = p_fp and created_at >= date_trunc('day', now());
  if v_today >= 10 then
    return json_build_object('success', false, 'limited', true,
      'limitReason', 'daily_cap', 'message', '今天已经点赞了 10 条，明天再来吧');
  end if;

  insert into thought_likes (target_id, fingerprint) values (p_target, p_fp);
  select count(*) into v_total from thought_likes where target_id = p_target;
  select count(*) into v_today from thought_likes
   where fingerprint = p_fp and created_at >= date_trunc('day', now());
  return json_build_object('success', true, 'liked', true, 'total', v_total, 'userToday', v_today);
end; $$;

-- 3) 批量读取点赞数
create or replace function get_thought_likes(targets text[])
returns table(target_id text, total bigint) language sql stable as $$
  select target_id, count(*) from thought_likes
   where target_id = any(targets) group by target_id;
$$;

-- 4) 权限：表对 anon 不可直接读写，仅开放 RPC
revoke all on thought_likes from anon, authenticated;
grant execute on function like_thought(text, text) to anon, authenticated;
grant execute on function get_thought_likes(text[]) to anon, authenticated;
```

```js
// 浏览器指纹（与原型一致：设备信息 → SHA-256）
async function fingerprint() {
  var parts = [navigator.userAgent, navigator.language, screen.width + 'x' + screen.height,
    Intl.DateTimeFormat().resolvedOptions().timeZone, String(new Date().getTimezoneOffset())];
  try {
    var c = document.createElement('canvas'); c.width = 200; c.height = 50;
    var x = c.getContext('2d'); x.fillText('fp', 2, 15); parts.push(c.toDataURL().slice(-50));
  } catch (e) {}
  var buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(parts.join('|||')));
  return Array.from(new Uint8Array(buf)).map(function (b) { return b.toString(16).padStart(2, '0'); }).join('').slice(0, 32);
}

var sb = window.supabase && window.supabase.createClient('YOUR_SUPABASE_URL', 'YOUR_SUPABASE_ANON_KEY');

// 挂到全局，供 initLike 调用
window.dogxiLike = function (id, cb) {
  if (!sb) return;
  fingerprint().then(function (fp) {
    sb.rpc('like_thought', { p_target: id, p_fp: fp }).then(function (res) {
      if (res.error) return;
      cb({ total: res.data.total });
    });
  });
};
```
